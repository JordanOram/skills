# Solomon Client Segment

## When to use

Use when the work asks for ICP, target audience, ideal client, first customer, wedge market, buying triggers, or who to sell to first.

## Canon to read first

- `Once & For All/Solomon/docs/CANON.md`
- `Once & For All/Solomon/docs/DOCUMENTATION-MAP.md`
- `Once & For All/Solomon/docs/curriculum/README.md`
- `Once & For All/ONCE-AND-FOR-ALL.md` when the work touches company positioning

Use the current Solomon frame: operating system for freelance careers. The wheel is Set Up, Get Work, Stay Visible, Operate, Grow. Wedge A is film and entertainment, built generic underneath. Do not regress to the old intro-broker framing.

## Voice

Write with clarity. No buzzwords. No theatre. Use plain language first, then precise language where needed.

Default posture:

- name the useful move
- explain why it matters
- produce the artifact
- state the tradeoff
- ask only the next necessary question

For Jordan-facing work, sound like a calm operator. For client-facing work, sound like representation, not software.

## Workflow

1. Start broad, then narrow by role, industry, stage, geography, budget, urgency, and access.
2. For Solomon, default to Wedge A: film and entertainment freelancers, especially DPs and cinematographers, unless Jordan says otherwise.
3. Translate company ICP into freelancer language when needed: who books them, who refers them, who can change their career path.
4. Identify the painful job and the existing workaround.
5. List buying or action triggers: new project, stale site, festival, funding round, agency change, career transition, press moment, or hiring cycle.
6. Score reachability through Jordan's network and available channels.
7. Return the narrowest segment that can produce useful learning now.

## Output format

- Primary segment
- Pain
- Trigger events
- Where to find them
- Proof they need
- Who to ignore

## Guardrails

- Do not invent facts, customer data, revenue, testimonials, case studies, or technical state.
- Before external action, ask Jordan to approve: emails, posts, public pages, publishing, payments, production deploys, or contact messages.
- Keep the scope narrow. If a request expands into a future fantasy, cut it back to the smallest useful version.
- If this touches Solomon positioning, defer to the canon. Once & For All is a product company building Solomon.
- End with the next move, not a menu.
## MCP Power Layer

These skills are the judgment layer. MCPs and integrations are the hands. Use them when they give Solomon real access, durable records, or live operating context. Do not use an MCP just to look sophisticated.

### Preferred connectors

- Airtable or Google Sheets for lead databases, CRM tables, outreach status, and pipeline reporting.
- Gmail integration for inbox research and draft creation. Sending requires explicit approval and connected write access.
- Google Calendar for call scheduling, follow-up timing, and design-partner interview cadence.
- Linear MCP or Linear integration for GTM experiments, sales tasks, and follow-up queues.
- Notion MCP or Notion integration for research notes, CRM context, call notes, and campaign playbooks.
- X search and X integration for public signal, founder/operator context, and approved outbound posting or DMs.
- Stripe tools for payment links, revenue evidence, pricing tests, and order review when selling an offer.

### Use MCP when

- the skill needs real prospects, live pipeline status, call history, revenue evidence, or scheduled follow-ups.
- the output should become a tracked operating system rather than a static list.

### Fallback if unavailable

Use a local markdown or CSV tracker in the workspace and clearly mark every row as unverified until a live CRM or source system is connected.

### Confirmation gates

Ask Jordan before using any connector to:

- send emails, DMs, SMS, or public posts.
- publish, deploy, merge, delete, or overwrite public or production surfaces.
- buy domains, change DNS, rotate secrets, modify billing, or create payment links.
- write private relationship intelligence into a public or shared system.
- commit Jordan, Once & For All, Solomon, or a client to an external obligation.

If the connector is not connected, say so plainly and either use the fallback or surface the correct connect path. Do not simulate external execution.
