# Solomon Cofounder Feature Skill Map

**Created:** 2026-06-19
**MCP-ready:** 2026-06-21

This map translates the Cofounder `how-to` capability pattern into Solomon-flavoured skills. These are not Cofounder clones. They are execution muscles for Solomon as the operating system for freelance careers.

Each `solomon-*` skill now includes an **MCP Power Layer** section:

- **Preferred connectors:** the integrations or MCPs that make the skill operational.
- **Use MCP when:** the conditions where live access matters.
- **Fallback if unavailable:** the manual or Zo-native path.
- **Confirmation gates:** the actions that require Jordan's approval before external execution.

Skills remain the judgment layer. MCPs are the hands. Automations are the timing layer.

## Routing principle

If the request serves a freelancer setting up, getting work, staying visible, operating, or growing, route to the Solomon-flavoured skill. If the request is generic marketing or engineering with no Solomon-specific context, use the existing generic skill.
